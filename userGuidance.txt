Here's a complete front-end testing guide for every section and button:

  ---
  InsureFlow Frontend Testing Guide

  0. Start the App

  # Terminal 1 — start the app
  ./start.sh

  # Or if already seeded:
  npm run dev

  Open http://localhost:3000 — you should auto-redirect to the dashboard (no login form).

  8. New Automation Jobs (Manual Trigger)

  Test the 3 new cron jobs via API:

  # Cross-sell detection
  curl http://localhost:3000/api/cron?job=cross-sell-detection

  # Client follow-up
  curl http://localhost:3000/api/cron?job=client-follow-up

  # Document expiration
  curl http://localhost:3000/api/cron?job=document-expiration

  # Run ALL jobs at once
  curl http://localhost:3000/api/cron

  After running, check:
  - Bell icon (notifications) — new notifications should appear
  - Marketing → Cross-Sell — new recommendations from the cross-sell job
  - Server logs — [Job] Completed: cross-sell-detection etc.
